## Технические решения
- **Конфигурация** через `.env.bot.secret` (уже загружается)
- **Тестирование** через `--test` — позволяет отлаживать handlers без Telegram
- **Разделение ответственности**:
  - `bot.py` — точка входа, парсер команд, запуск
  - `config.py` — настройки
  - `handlers/` — файлы с конкретными обработчиками (позже)
  - `services/` — клиенты для API (LMS, LLM)
